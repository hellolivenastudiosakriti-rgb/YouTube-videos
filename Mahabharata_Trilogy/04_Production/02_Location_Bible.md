# महाभारत त्रयी — LOCATION & STYLE BIBLE (LOCKED v1.0)
**Rule:** har location ka **ek master plate** (establishing image) banega aur har shot mein wahi plate + wahi DNA text jayega. Roshni (subah/raat/toofan) sirf prompt mein badlegi — naya plate tabhi jab set khud badle (jaise Indraprastha ka nirmaan, Khāṇḍava jal jaana).
**Design base (World Bible §4):** Painted Grey Ware Iron Age (c. 1100–800 BCE) — mud-brick, sal timber, lime plaster, hand-loom cotton, wild silk, deerskin, clay oil-lamps, spoked-wheel chariots, real seashell conches. Koi marble palace, koi neon, koi glass-and-gold fantasy nahi.
